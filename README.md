# JavaScript Practice Collection

A curated collection of beginner-to-intermediate JavaScript exercises and browser-based mini applications. The projects are organized by topic while preserving the original exercise code.

## Repository Structure

| Section | Topics | Files |
|---|---|---|
| [01 - Fundamentals](01-Fundamentals/) | Arithmetic, geometry, loops, prompts, and basic DOM output | Day 2, Day 3 |
| [02 - Functions & Validation](02-Functions-and-Validation/) | Functions, arguments, rest parameters, error handling, prime numbers, strings, math, and input validation | Day 4, Day 5 |
| [03 - Arrays](03-Arrays/) | Numeric operations, array mutation, filtering, and mapping | Day 6, Day 7 |
| [04 - Objects & OOP](04-Objects-and-OOP/) | Objects, data validation, tables, classes, relationships, getters/setters, and inheritance | Day 9, Day 10 |

## Getting Started

1. Clone or download this repository.
2. Open any `.html` exercise directly in a modern browser.
3. For standalone `.js` exercises, include the file in an HTML page using a script tag, or run it in the browser developer console. These exercises use browser APIs such as `prompt()`, `alert()`, and the DOM.

Example:

```html
<script src="./01-Fundamentals/Day2-Arithmetic-and-Geometry.js"></script>
```

## Learning Topics

- JavaScript variables, data types, type conversion, and operators
- Conditional logic and loops
- Browser dialogs and DOM manipulation
- Functions, parameters, rest parameters, and return values
- Arrays and common array methods
- String processing and regular expressions
- Input validation and basic error handling
- Objects, classes, encapsulation, relationships, and inheritance

## Notes

- This repository consolidates selected practice exercises from separate repositories into one organized learning collection.
- The original repositories are left unchanged; this collection is an additional, organized copy.
- Some exercises are intentionally simple and demonstrate specific concepts rather than production-ready application patterns.
- Review user input and output handling before reusing these examples in real applications.
- These exercises are learning projects; they are not intended as production-ready applications.
